# DESIGN — InvoicePro Light Theme Login Page

## 1. Design Overview

InvoicePro Login is a modern, professional SaaS authentication page designed for an invoice management application.

The design must use a clean **LIGHT THEME** with:

- White login card
- Very light blue background
- Blue primary actions
- Soft shadows
- Rounded corners
- Minimal decorative elements
- Clear typography
- Strong visual hierarchy
- Responsive layout

The design should feel:

- Professional
- Trustworthy
- Modern
- Clean
- Simple
- Premium
- Easy to use

Do NOT create a dark theme.

Do NOT redesign the approved layout.
